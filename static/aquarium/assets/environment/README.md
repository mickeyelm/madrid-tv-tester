# Aquarium surface scans

Seven unmodified 1024-pixel JPG maps, downloaded 2026-09-05 from Poly Haven.
All are CC0-1.0: https://polyhaven.com/license . The aquarium loads these local
copies; it makes no runtime requests to Poly Haven or its API.

- **Rock Face 03** — Dario Barresi (photography), Rico Cilliers (processing).
  https://polyhaven.com/a/rock_face_03
  Diffuse, OpenGL normal and roughness maps.
- **Sand 01** — Rob Tuytel. https://polyhaven.com/a/sand_01
  Diffuse, OpenGL normal and roughness maps.
- **Coast Sand Rocks 02** — Rob Tuytel.
  https://polyhaven.com/a/coast_sand_rocks_02
  Diffuse map, blended into the planted banks beside the sand path.

`sources.json` records exact download URLs, file sizes and SHA-256 hashes.
Diffuse maps use sRGB; normal and roughness maps remain linear.
